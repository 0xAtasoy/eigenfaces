# Eigenfaces

## Dataset

This project uses the AT&T (ORL) Database of Faces: 40 subjects, 10 grayscale images each (92×112, `.pgm`).
The images are not included in this repository.

1. Download the dataset from https://www.kaggle.com/datasets/kasikrit/att-database-of-faces
2. Unzip it and copy its contents (`s1/` … `s40/`) into the existing `data/att_faces/` folder.
3. Check that the path `data/att_faces/s1/1.pgm` exists.

Original source: AT&T Laboratories Cambridge,
https://www.cl.cam.ac.uk/research/dtg/attarchive/facedatabase.html
